Getting started

Where do I find my API key?
  1. Sign in at clockify.me.
  2. Click your avatar in the top-right corner and choose Preferences.
  3. Open the Advanced tab and click Manage API keys.
  4. Click Generate new and paste the key above. Clockify shows it only once.
What does the app read?

Only your own profile (to find your workspace) and your time entries for the selected range. Nothing is ever written back to Clockify.

Self-hosted server

Sign in to the time tracking server you run yourself, for example on a NAS. The README explains how to set one up.
